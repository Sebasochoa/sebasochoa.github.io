Proyectos

Planificador de rutas de transporte público – Arequipa

Aplicación web para planificar rutas en transporte público en Arequipa. Usa la Google Maps JavaScript API para trazar las rutas existentes y calcular trayectos entre paraderos, y Google Places para buscar destinos. Hecha con HTML5, CSS3 y JavaScript.

  • Rutas, paraderos e instrucciones paso a paso sobre el mapa.
  • Interfaz responsiva, con carga asíncrona y manejo de errores.
github.com/Sebasochoa/Planificador_Rutas

Automatización de entrega de materiales educativos

Script en Python y Selenium que lee y completa datos dentro de un sistema institucional, para reemplazar el registro manual de la entrega de materiales educativos.

  • Automatiza flujos repetitivos sobre un sistema ERP.
  • Valida los datos y maneja excepciones antes de registrar.
github.com/Sebasochoa/Entrega_Textos

Plataforma de Bolsa Laboral

Plataforma full-stack para gestionar ofertas laborales, postulaciones y usuarios (estudiantes, empresas, profesores y administradores). API REST con Spring Boot 3 y Java 17, base de datos PostgreSQL y frontend en React 18 con Vite.

  • Autenticación, control de acceso y navegación por roles.
  • Filtros de ofertas y gestión de CV.
github.com/Sebasochoa/BolsaLaboralUnsa
